internet

A worldwide network that connects computers and devices.

web

A collection of websites and web pages available through the Internet.

internet vs web

The Internet is the network; the Web is a service that runs on that network.

ASCII

A character coding system for English letters, numbers, and symbols.

unicode

A character standard that supports characters from many languages and symbols.

UTF-8

A way of encoding Unicode characters so computers can store and display text.

URL

The address of a web page or resource on the Internet.

domain name

Domain Name:

The name of a website.

>HTTP

A protocol used to transfer web pages between a browser and a server.

HTTPS:

A secure version of HTTP that encrypts data.

IP Address:

A unique numerical address used to identify a device on a network.

DNS:

A system that converts domain names into IP addresses.

W3C Recommendations

Web standards and guidelines created by the World Wide Web Consortium (W3C).

ML:

XHTML

HTML:
