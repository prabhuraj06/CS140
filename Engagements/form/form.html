The action attribute specifies where the form data will be sent when the user submits the form. It usually contains the URL of the page or server that processes the information.

The method attribute specifies how the form data will be sent to the server. The two most common methods are GET and POST.

GET: Sends form information through the URL as part of the query string. The information is visible in the address bar and can be bookmarked. POST: Sends form information in the request body rather than the URL. The information is not displayed in the address bar and is better for submitting sensitive or large amounts of data. HTTPS is still needed to protect sensitive information.

A preset value is information that is already entered into a form control. A placeholder is a hint that appears inside an empty field and disappears when the user starts typing. Text box: Use the value attribute to set a preset value. Use placeholder to show a hint. Textarea: Put the preset text between the opening and closing
